# 🧰 Reel Deal 1.1.0

Greetings!

After a long week of review, the Reel Deal was approved by the Modrinth Team. Due to my unfortunate timings, the 26.3 drop version was released in the meanwhile. Therefore, why don't we polish the datapack again, roll back a few features for the potential future comeback, resolve a few bugs, and release it for 26.3?

The sunflower plains were (essentially added) to as a junk biome. The same happened to the newly added **Dappled Forest**. The advancements related to crafting permutions of rods were fixed and now are properly granted. The fisherman trades were removed – I'm not satisfied with how they turned out: they are a subject to be returned in future versions.

And a **huge** amount of codebase modifications to align with the new 26.3 standards.

Have fun with 1.1.x!

# 🧰 Reel Deal 1.0.0

Greetings!

I'm excited to (finally) publish the first Reel Deal release after weeks of work. The 1.0.0 release includes the basics: **5 Hooks**, **3 Lines**, and **5 biome-specific Fish**.

<center>

| Hook    | How to Obtain                           |
| ------- | --------------------------------------- |
| Wooden  | Junk Catch                              |
| Iron    | Crafting Table                          |
| Cluster | Treasure Catch (Underground, `y <= 48`) |
| Anchor  | Treasure Catch (Ocean)                  |
| Golden  | Treasure Catch (Anywhere else)          |
</center>

Alongside the basic additions, some advancements that I felt were meaningful were added. There isn't "change" on the first release, therefore I see no point in keeping the changelog any longer.

Enjoy **Reel Deal**!
